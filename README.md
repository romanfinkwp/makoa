# Makoa

[![WordPress.org version](https://img.shields.io/wordpress/theme/v/makoa)](https://wordpress.org/themes/makoa/) [![Active installs](https://img.shields.io/wordpress/theme/installs/makoa)](https://wordpress.org/themes/makoa/) [![License: GPL v2 or later](https://img.shields.io/badge/license-GPLv2%2B-blue)](https://www.gnu.org/licenses/gpl-2.0.html)

Makoa is a minimalist theme for personal websites. Create your perfect website with just a few clicks, and share all the awesome things you do with the world!

![Screenshot](screenshot.png)

- **WordPress.org:** https://wordpress.org/themes/makoa/
- **Live preview:** https://wp-themes.com/makoa/

## Installation

1. Check you version of WordPress, it should be 6.7 or later.
2. Upload the theme.
3. Activate the theme.

To install the development version from this repository, download it as a ZIP (Code > Download ZIP), rename the folder inside to `makoa` and upload it in Appearance > Themes > Add New Theme > Upload Theme.

## Requirements

- WordPress 6.7 or later
- Tested up to WordPress 7.1
- PHP 7.4 or later
